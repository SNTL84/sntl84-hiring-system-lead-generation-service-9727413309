## 🎯 What This Does

**An AI-Powered Hiring Intelligence System** that eliminates manual resume screening for small businesses, agencies, and startups. Built for founders who are tired of spending hours filtering candidates — this does it in seconds.

> *"Most hiring tools cost ₹10,000+/month. This is self-hosted, zero API cost, and takes 10 minutes to deploy."*
